# BadmintonAI

아이폰에서 배드민턴 복식 경기 영상을 분석하는 개발 중인 앱입니다.

코트와 선수의 움직임, 셔틀콕 궤적을 분석해 경기 영상을 이해하기 쉬운 형태로 보여주는 것을 목표로 합니다. 영상은 서버로 전송하지 않고 기기 안에서 처리하는 방향으로 개발하고 있습니다.

## 이 앱은 어떤 앱인가요?

사용자가 아이폰으로 촬영한 배드민턴 복식 경기 영상을 선택하면, 앱이 영상 속 코트와 네 명의 선수를 분석합니다. 분석 결과에는 선수의 움직임과 셔틀콕이 이동한 경로가 표시되고, 경기 장면을 다시 확인할 수 있는 결과 영상과 분석 기록이 만들어집니다.

즉, 단순히 영상을 재생하는 앱이 아니라 **경기 영상을 입력받아 경기 흐름을 다시 살펴볼 수 있는 자료로 바꾸는 앱**입니다. 선수들이 어느 위치에서 움직였는지, 셔틀콕의 흐름이 어떻게 이어졌는지 확인하는 데 도움을 주는 것을 목표로 합니다.

현재는 개발 중인 프로토타입으로, 모든 경기 상황에서 완벽한 선수 추적이나 타격 판정을 보장하지 않습니다. 특히 선수 번호의 연속성, 다양한 촬영 각도에서의 안정성, 타격 시점의 정확도는 계속 검증하고 있습니다.

### 사용 흐름

1. 경기 영상을 앱에 불러옵니다.
2. 앱이 코트와 선수, 셔틀콕의 움직임을 분석합니다.
3. 분석이 끝나면 움직임이 표시된 결과 영상과 분석 기록을 확인합니다.

분석은 서버에 영상을 업로드하지 않고 아이폰 안에서 수행하는 방향으로 설계했습니다. 따라서 영상의 외부 전송을 줄일 수 있지만, 기기 성능과 영상 길이에 따라 분석 시간이 달라질 수 있습니다.

## 포트폴리오 요약

- iOS 기반 온디바이스 영상 분석
- Swift, SwiftUI, Core ML, AVFoundation 활용
- 컴퓨터 비전 모델을 실제 앱 흐름에 연결하고 실기기에서 검증
- 모델 결과뿐 아니라 영상 입력, 처리 시간, 실행 상태와 검증 한계까지 함께 점검

개발 과정에서는 전용 모델의 성능이 예상보다 낮았던 사례, Debug와 Release 측정 결과가 달랐던 사례, 백그라운드 실행 중 결과 품질이 달라질 수 있었던 사례를 확인했습니다. 각 문제는 실패 장면 수집, 배포 조건 측정, 실행 경로 점검으로 분리해 다뤘습니다.

이 프로젝트에서 중요하게 본 기준은 단순히 숫자를 높이는 것이 아니었습니다. 어떤 조건에서 측정했는지, 무엇을 아직 검증하지 못했는지, 결과를 만든 경로가 무엇인지 함께 설명할 수 있어야 했습니다.

이 저장소는 프로젝트 소개용 포트폴리오입니다. 앱 소스코드, 핵심 분석 로직, 모델 학습·변환 도구, 상세 설계, 모델 가중치, 학습 데이터, 경기 영상은 공개하지 않습니다.
